About This System

South Indian Temple Heritage Monitoring & Structural Analysis

🛕 Purpose

This system uses AI-powered computer vision to monitor and analyze South Indian temple heritage sites. It detects key structural elements — Lingam, Nandhi, Temple Structures, Sheds, and inferred Avudaiyar bases — and tracks changes between inspection images over time.

🔬 Technology

  • Object Detection: YOLOv8 custom-trained model with Test-Time Augmentation (TTA)
  • Image Quality: Laplacian blur detection, brightness & noise analysis
  • Similarity: SSIM (Structural Similarity Index) with structural vs illumination change classification
  • Change Detection: IoU-based object matching with anomaly detection
  • Domain Validation: South Indian temple spatial relationship rules
  • Duplicate Detection: Perceptual hashing (pHash)

📐 Architecture

  • Backend: Flask REST API with OpenCV, scikit-image, PyTorch
  • Frontend: Vanilla HTML/CSS/JS — zero external frameworks
  • Model: Custom YOLOv8 trained on South Indian temple dataset

🕉️ Lingam 🐂 Nandhi 🛕 Temple Structure 🏚️ Shed / Auxiliary ⬡ Avudaiyar (Inferred)
